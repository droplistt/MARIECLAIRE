# Marie Claire Paris Salon — Malleshwaram

Static website adapted from the supplied Maison Éclat ZIP for Marie Claire Paris Salon, Malleshwaram, Bengaluru.

## Files
- `index.html` — page content and salon information
- `styles.css` — responsive styling
- `script.js` — navigation, service filters, reveal effects, and WhatsApp enquiry form

Service categories are based on the salon's published service categories. Prices, individual staff biographies, invented testimonials, membership packages, and unverified offers have deliberately not been fabricated. Stock photos are used as visual inspiration and should be replaced with the salon's approved photos before final launch.
